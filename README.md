## 🚀 Local Development

```bash
# Clone the repo
git clone https://github.com/shashank-jumbarthi/portfolio.git

# Open directly in browser
open portfolio/index.html

# Or serve locally with any static server
cd portfolio && npx serve .
```

Edit `index.html` for content and `styles.css` for styling. Push to `main` to deploy.

## 🌍 Deployment

The site is deployed via **GitHub Pages**. Any push to the `main` branch triggers an automatic deploy:

```
Settings → Pages → Source: Deploy from branch → Branch: main (/root)
```

The site is available at `https://shashank-jumbarthi.github.io/portfolio/`.

### Custom Domain

To use a custom domain:
1. Add a `CNAME` file or configure in repo Settings → Pages → Custom domain
2. Update your DNS provider with a `CNAME` record pointing to `shashank-jumbarthi.github.io`
3. Enable HTTPS enforcement in Pages settings
